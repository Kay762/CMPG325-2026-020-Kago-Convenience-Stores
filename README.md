Project Overview

This project involves the design and simulation of a computer network for Kago Convenience Stores in Kimberley.

Client Requirements

The network must:

- Provide appropriate connectivity for staff devices.
- Use the assigned "192.168.19.0/24" addressing block.
- Keep the two departments logically separated.
- Provide wireless connectivity through access points.
- Demonstrate Wireless LAN integration and coverage.
- Accommodate 8 additional staff members in one department without redesigning the network.
- Provide a working and testable Packet Tracer implementation.
- Document important design decisions and evidence in GitHub.

Network Design

The network uses VLANs to logically separate the two departments and access points to provide wireless connectivity.

- VLAN 10: Department 1 — "192.168.19.0/25"
- VLAN 20: Department 2 — "192.168.19.128/25"

Milestone 1

The Milestone 1 submission consists of:

1. Client Requirements
2. Physical Topology
3. Logical Topology
4. IP Addressing Plan
5. Initial GitHub Repository

The network is being designed and simulated using Cisco Packet Tracer.
