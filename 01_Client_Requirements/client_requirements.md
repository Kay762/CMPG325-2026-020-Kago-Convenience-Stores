Client Requirements

1. Client Information

Organisation: Kago Convenience Stores
Location: Kimberley
Industry: Retail
Client ID: CLI-020
Project ID: CMPG325-2026-020

2. Network Requirements

Kago Convenience Stores requires a computer network that provides reliable connectivity for staff devices and supports the organisation's day-to-day operations.

The network must:

- Provide appropriate connectivity between authorised devices.
- Use the assigned "192.168.19.0/24" IP addressing block.
- Support both wired and wireless devices.
- Provide wireless connectivity through access points.
- Provide a working and testable network implementation in Cisco Packet Tracer.

3. Department Separation

Two departments share the same floor and must remain logically separated.

The network will use separate VLANs to achieve this:

- VLAN 10 — Department 1
- VLAN 20 — Department 2

This provides logical separation while allowing the network to use the same physical switching infrastructure.

4. Wireless LAN Requirement

The assigned networking challenge is:

Wireless LAN — AP Integration & Coverage

The network must include access points that provide wireless connectivity to staff devices.

The wireless design will use:

- AP1 — Department 1 / VLAN 10
- AP2 — Department 2 / VLAN 20

Wireless devices must be able to connect to the appropriate access point and communicate with their department's network gateway.

5. Scalability and Change Request

The client has requested that the network accommodate 8 additional staff members in one department.

The solution must provide the additional capacity without redesigning the existing network.

The IP addressing and VLAN design therefore needs sufficient available addresses for future staff devices.

6. Network Design Requirements

The network design must:

- Use Cisco Packet Tracer for simulation.
- Include appropriate routers, switches, access points and end devices.
- Use the assigned IP addressing block.
- Use VLANs to separate the two departments.
- Provide routing between the required network segments.
- Support the assigned Wireless LAN challenge.
- Allow the network to be tested and verified.

7. Testing Requirements

The completed network must be tested to verify:

- Wired device connectivity.
- Wireless device connectivity.
- Connectivity to the correct default gateway.
- Correct VLAN membership.
- Wireless access point integration.
- Successful operation of the network after the required configuration.

Important troubleshooting steps and successful test results will be documented as project evidence.

8. Documentation Requirements

The project must be documented in an individual GitHub portfolio.

Documentation will include:

- Client requirements.
- Physical topology.
- Logical topology.
- IP addressing plan.
- Packet Tracer implementation.
- Configuration evidence.
- Testing results.
- Troubleshooting performed.
- Relevant screenshots.
- Design decisions and reflections.
